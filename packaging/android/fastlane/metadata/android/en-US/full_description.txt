Corvene Legacy is the desktop Corvene application itself on Android: a native Git client with the interface of GitHub Desktop, written in Rust, keeping the desktop layout 1:1 for tablets, Chromebooks and desktop modes. Phones are better served by Corvene for Android, the app built for them; both install side by side.

- Clone, commit, branch, merge, rebase, stash, cherry-pick, push and pull
- Diffs with syntax highlighting, line and hunk selection
- GitHub sign-in, pull requests and their checks, notifications
- Git, Git LFS and an SSH client are built in; no other app is needed
- Repositories are kept in the app's own storage and shown to editors and file managers through the system file picker
- Opens a repository on shared storage in Termux

No telemetry and no usage statistics.
